# سجل تغيير النسخة 0.3

- راجعنا الفيديو بلقطات مرقمة من الثانية 00 إلى الثانية 78 وحددنا الأجزاء التي ينطبق عليها نطاق Velnix.
- أعيد ضبط اختيار شركة توصيل ليظهر للمخوّل فقط، ومنع تغيير شركة أرشفت أو تعطلت.
- قُيّدت تغييرات الحالات اليدوية بالمراحل التشغيلية. حالات التوصيل الخارجية لا تُختلق بضغط زر.
- أُزيل عرض المبالغ لموظف المستودع في بطاقات الشركات، وأتيح له عرض الشركات والطلبات التابعة له دون تعديل إعدادات API.
- تحسّن تخطيط النموذج باعتماد عمودين للشاشات الواسعة، وتحسين الشعار على الهواتف الضيقة.
- أعيد تنظيم صلاحيات الحسابات الموقوفة وإدارة حساب المدير العام.
- أصبحت قراءة الإشعارات خاصة بكل موظف وليست مشتركة بين الجميع.
- أُضيف فلتر شركة التوصيل لقائمة الطلبات، ودعم الأرقام العربية في الكمية والمبلغ والهواتف.
- أضيف اختبار منطق حالات وانتقالات وصلاحيات، واختبارات تجاوب مكتوبة لستة عروض شاشة.

**حالة التحقق:** فحص هيكلي واستيراد ملفات ناجح، دون تشغيل Flutter SDK؛ لا يمكن إعلان اجتياز اختبار بناء/تصميم مرئي قبل تنفيذ Open Code لبروموت التدقيق رقم صفر.

## v0.4 — مراجعة كود إضافية قبل Open Code

- تصحيح بطاقة كل الطلبات لتكون مجموعة شاملة، مع إبقاء بطاقة التوصيل جزءاً منها.
- عمليات تحديث الطلب والموظف والشركة أصبحت تمر عبر تحقق DemoStore، وليس تغيير الحقول قبل التأكيد.
- تعيين موظف مبيعات مسؤول لمدخلي البيانات؛ منع الاطلاع على فريق غير مسند.
- منع إسناد شركة غير صالحة، ومنع الإلغاء اليدوي للحالات الخاضعة لشركة التوصيل.
- صيانة نسب المبالغ للمدير حسب إذن قابل للتخصيص، وحماية المدير العام الوحيد.
- فلترة شرائح الحالات بناءً على البحث والشركة والتأخير، وحماية الإشعارات عند توقف الحساب.
- إضافة لوحة تركيز مختلفة لكل دور، والتحقق الأولي من أرقام الهواتف.
- إضافة اختبارات انحدار غير منفذة؛ لا يوجد Flutter SDK للتشغيل في بيئة المراجعة.
