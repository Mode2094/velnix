## 3. أوامر التحقق (ينفّذها المهندس بعد وصول الملفات)

```bash
cd docs/evidence-import

# تحقق من ملف واحد
shasum -a 256 click/ClickApi.postman_collection.json

# أو تحقق من كل الملفات دفعة واحدة
shasum -a 256 -c KNOWN_GOOD.sha256
```

تفسير النتيجة:

- `OK` → مطابق بايت-ببايت للأدلة التي حُلّلت سابقاً → يُعتمد.
- `FAILED` → **مُغيَّر أو مُعدَّل**. لا يُعتمد. تُراجَع كل نتيجة تعتمد عليه.
