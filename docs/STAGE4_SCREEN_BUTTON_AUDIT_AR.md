# Stage 4 — تدقيق الشاشات والأزرار

> **الحالة: PARTIAL** — ما جرى فحصه مُثبت أدناه؛ وما لم يُفحص مُصنَّف صراحةً.

## 1. الشاشات المُختبَرة فعلياً (تنقّل حقيقي + تأكيد خلفي)

| الشاشة | التنقل | تأكيد مستقل |
|---|---|---|
| لوحة المتابعة | ✅ تبويب الرئيسية | `dashboardStats` 200 |
| قائمة الطلبات + التصفية | ✅ تبويب الطلبات | `listOrders` 200 |
| البحث | ✅ حقل البحث | `searchOrders` بالوسم ⇒ **نتيجة واحدة** |
| إنشاء طلب | ✅ نموذج حقيقي | `createOrder` ⇒ `id` + حمولة صحيحة |
| تفاصيل الطلب | ✅ نقرة على الطلب | `getOrder` + سجل الحركة |
| تعديل الطلب | ✅ زر «تعديل» | `updateOrder` + `revision` |
| التحويلات + الإكمال الداخلي | ✅ 4 تحويلات | `changeOrderStatus` + قفل |
| الإشعارات + القراءة | ✅ تبويب الإشعارات | `listNotices` + `read=true` |
| سجل العمليات | ✅ «المزيد» | `listAudit` |
| شاشة الأخطاء | ✅ قطع الشبكة | استعادة بلا نجاح مُختلق |
| الإلغاء | ✅ نافذة تأكيد | `cancelled` + الحدث محفوظ |

## 2. الأزرار المُختبَرة

| الزر | النتيجة |
|---|---|
| «المتابعة باستخدام Google» | ✅ يفتح النافذةSynthetically |
| تبويبات التنقل الستة | ✅ كلها تُبحر |
| «تعديل» | ✅ يفتح المحرّر |

| تحويلات الحالة الأربع | ✅ تعمل بالتسلسل |
| «إكمال الطلب الداخلي» + «تأكيد الإكمال» | ✅ **تأكيد من خطوتين** |
| «تحويل إلى ملغي» + «تأكيد الإلغاء» | ✅ |
| «تحديث البيانات» / «تحديث» | ✅ |
| «تفعيل إشعارات الجهاز» | ✅ يعرض رسالة الإعداد الناقصة بصدق |
| «طباعة / PDF / باركود» | ⬜ **NOT TESTED** |
| «اختيار شركة توصيل» | ⬜ **NOT TESTED** — لا مزوّد |
| «رجوع» | ✅ يغلق المسارات fullscreen |
