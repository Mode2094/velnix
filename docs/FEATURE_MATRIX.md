# جدول قبول الميزات

| الميزة | حالة القبول | الدليل والحدود |
|---|---|---|
| إنشاء وقراءة الطلب للأدوار الخمسة | مكتمل ومختبر | Auth/Firestore محلي ونماذج ببوابة محقونة |
| إكمال الطلب الداخلي | مكتمل ومختبر | سياسة جميع الحالات، معاملة وتوثيق مصدر، تأكيد واجهة وتحديث |
| البحث والفلاتر والفرز والتصفح | مكتمل ومختبر | استعلامات محلية؛ فهارس/تكلفة staging خارجية |
| عدادات >10000 ونطاق فريق >30 | مكتمل ومختبر | fixtures محاكيات؛ لا قياس زمن خدمة منشورة |
| قوائم موظفين وشركات >100 | مكتمل ومختبر | 137 لكل قائمة، pagination وبحث مستقر؛ creators scoped 120 |
| PDF وخط عربي وباركود رقمي | مكتمل ومختبر | ملفات فعلية وقراءة صور؛ بعض الصور تحتاج preprocessing معلناً |
| الطابعة والماسح | محجوب بإعداد خارجي | أجهزة وطرازات غير متاحة |
| إشعارات داخلية ومقروء مستقل | مكتمل ومختبر | حدث دائم، منع تكرار وحالة قراءة |
| استعادة محاولات الدفع | مكتمل ومختبر | FCM محقون ومعاملات محاكي؛ لا شهادة تسليم فعلي |
| FCM على أجهزة/خلفية/Web worker | منفذ وغير مختبر خارجياً | يلزم مشروع وVAPID وأذونات وأجهزة |
| البريد/جلسة عضوية/تعطيل/تفويض | مكتمل ومختبر | Auth محلي وتحقق handlers؛ منصة منشورة خارجية |
| Google/OAuth/App Check | منفذ وغير مختبر خارجياً | SHA وClient IDs وإعداد المشروع |
| KMS/شركة توصيل حقيقية | محجوب بإعداد خارجي | مرجع مفتاح IAM ووثائق sandbox وعقد شركة واحدة |
| generic_v1 والـWebhook | مكتمل ومختبر | reference/mock contract فقط؛ ليس شركة فعلية |
| إعدادات مؤسسة وتقارير حالة وعمليات | مكتمل ومختبر | حفظ محلي وwidgets؛ تقارير الموظف عبر فلتر المنشئ |
| Web/Android Demo وLive build | منفذ وغير مختبر خارجياً | بناء Live لا يشغّل Firebase فعلياً؛ النتائج في TEST_RESULTS |
| iOS/release signing | محجوب بإعداد خارجي | macOS وتوقيع واختبارات جهاز |
| CI والتبعيات والأسرار | منفذ وغير مختبر خارجياً | workflow محدث؛ قراءة GitHub API قد تكون محجوبة |
| اعتماد الهوية/الأيقونات الأصلية والوصول على جهاز | ناقص | يحتاج مراجعة منتج وTalkBack/VoiceOver |
| تشغيل/نسخ احتياطي/استعادة/أداء وتكلفة | محجوب بإعداد خارجي | staging وأهداف RPO/RTO وميزانية |

مكتمل ومختبر يعني ضمن البيئة المحددة في الدليل فقط. لا يدل على اجتياز قبول إنتاج. لا نظام مخزون أو محاسبة متقدمة أو متجر في هذا العمل. التقارير الأساسية لا تقدم تحليلات إنتاجية متعددة المقاييس، والتنبيه الصوتي غير معتمد على جهاز.
