# مصفوفة الميزات
| الميزة | الحالة | حد التحقق |
|---|---|---|
| إنشاء الطلب لكل الأدوار | مطبق | محاكيات + widget ببوابة محقونة |
| تعديل/مراجعة/تعيين/إرسال | مطبق مع حماية معاملات | شركة فعلية غير موصلة |
| بحث هاتف/اسم/باركود وفلاتر وترتيب | مطبق | فهارس staging لم تنشر |
| عدادات وتقارير بحسب الصلاحية | مطبق | اختبار 10005، زمن الإنتاج غير مقاس |
| إدارة أعضاء وشركات وأرشيف | مطبق | Auth محلي؛ KMS خارجي |
| إعدادات المؤسسة والطباعة العربية | مطبق | PDF حقيقي؛ الطابعة والماسح خارجيان |
| إشعارات داخلية | مطبق دائم | محاكي |
| Google وFCM وApp Check | الكود جاهز للإعداد | تحقق الأجهزة والمشروع الحقيقي معلق |
| Android/Web | build محلي | Android debug؛ Web demo |
| iOS | ملفات منصة | يلزم macOS وتوقيع |
| CI | workflow مضاف | لم يشغل على GitHub |

التقارير الحالية ملخص حالات وفلاتر شركة/موظف/تاريخ؛ أداء الموظف يُراجع بتصفية منشئ الطلب، وليس لوحة مؤشرات إنتاجية متعددة المقاييس. التنبيه الصوتي يعتمد دعم وإعدادات المنصة، ولم يختبر أو يعتمد على جهاز. الأيقونات الأصلية للمنصات واعتماد الهوية البصرية باقٍ ضمن متطلبات الإطلاق.
