# الأدوار والصلاحيات
الخادم هو المرجع؛ إخفاء زر لا يمنح حماية. يجب أن يكون active=true وأن يكون الدور معروفاً.

| الدور | إنشاء | نطاق الطلبات الافتراضي | صلاحيات أصلية |
|---|---|---|---|
| generalManager | نعم | الجميع | جميع الصلاحيات |
| manager | نعم | ملكه | الصلاحيات المفوضة صراحة |
| warehouse | نعم | الجميع | عرض الجميع وتغيير الحالة |
| sales | نعم | ملكه ومدخلو بيانات فريقه الحالي | نطاق الفريق |
| dataEntry | نعم | ملكه | إنشاء وعرض ملكه |

صلاحية عرض الجميع توسع النطاق؛ المبالغ تظهر للمالك أو حامل viewAmounts. صلاحيات تعديل/إرسال/إدارة أعضاء/شركات/إعدادات مستقلة. الأفعال المسموحة يرسلها الخادم بحسب الحالة والمالك. الطلب المرسل أو قيد الإرسال لا يعدل يدوياً. المدير المفوض لا يمنح صلاحيات أو دوراً بصلاحيات أصلية تتجاوز سلطته. منع تعطيل آخر مدير عام نشط بمعاملة. نقل الفرق لا يمنح المشرف السابق وصولاً تاريخياً. تفاصيل السياسة التنفيذية في functions/src/policy.js وindex.js.

| الإجراء | شرط الخادم |
|---|---|
| بيانات العميل/طباعة | طلب داخل نطاق القراءة، وجلب جديد عند الطباعة |
| تعديل | ملكه في created/review؛ أو editAllOrders في الحالات الداخلية المسموحة |
| تغيير/إلغاء | updateOrderStatus أو warehouse/generalManager؛ انتقال داخلي صالح فقط |
| تعيين/إرسال | sendToDelivery، جاهز وشركة مفعلة وإرسال غير محجوز |
| التقارير | viewReports، مع نطاق القراءة وviewAmounts للقيم |
| الموظفون/تفويض الصلاحيات | manageEmployees، حدود تفويض الدور والصلاحيات وحماية آخر مدير |
| إدارة شركات | manageCompanies؛ مفاتيح لا تعاد إلى العميل |
| سجل عمليات/مزامنة/إعدادات | viewAudit/viewSync/manageSettings على التوالي |

اختبرت حسابات الأدوار الخمسة منفصلة بالمحاكيات، وأمثلة رفض ومنح وتعارض، وليس كل احتمال في حاصل ضرب جميع الصلاحيات. طباعة ملف لا تمنح صلاحية مالية جديدة.

الإكمال الداخلي delivered يتطلب ready وحق updateOrderStatus أو الدور warehouse/generalManager؛ لا شركة/hasDelivery ولا تتبع/remoteStatus ولا sending/sent/needs_review. completionSource=internal مع actor/time وسجل التدقيق. carrier delivery وحده يأتي من remote processor؛ terminal states لا تعاد فتحها. حالة قديمة delivered بلا مصدر تبقى بلا ادعاء مصدر. اختبارات policy تغطي كل الدور/الحالة/الهدف المذكور للإكمال، واختبار واجهة يفحص التأكيد وإزالة الفعل بعد الإكمال.
