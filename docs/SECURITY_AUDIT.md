# مراجعة الأمان
تمت معالجة: حسابات غير نشطة، أدوار/صلاحيات مشوهة، تصعيد الأدوار الأصلية، نطاق الفرق القديم، سباق تعطيل المديرين، مراجعات الطلب المتعارضة، تجاوز إرسال الشحنة، إظهار المبالغ، URL غير موثوق وإعادة التوجيه، حدود جسم استجابة المزود ومهل الشبكة، HMAC وطابع زمني ومنع تكرار أحداث webhook، وسجلات أخطاء لا تطبع مفاتيح أو بيانات عميل.

قواعد Firestore تختبر منع CRUD المباشر لكل الأدوار، وقراءة الملف الشخصي فقط. KMS مفعل في الكود، lazy وtimeout، لكنه لم يتصل بمفتاح حقيقي. TLS والتحقق من الشهادات لم يعطلا. release يمنع App Check debug، وGoogle/Push متوقفان حتى تهيئة صريحة. ملفات العميل العامة ليست اعتماد إدارة؛ لا توضع private keys في التطبيق أو المستودع.

لم تنفذ مراجعة اختراق خارجية أو تدقيق supply-chain شامل، ولم يختبر App Check على callable منشور. يلزم تسجيل مراقبة وتنبيهات، أقل صلاحيات IAM، سياسات احتفاظ وحذف بيانات، وحدود إساءة الاستخدام على staging. لا يشغل bootstrap أو backfill على الإنتاج بلا موافقة ونسخة احتياطية.

فحص npm audit --omit=dev للتبعيات الإنتاجية أعاد صفر ثغرات معروفة بتاريخ التحقق. هذا وصف لقائمة advisories الحالية فقط، ولا يثبت خلو التطبيق من الثغرات. توجد تحذيرات deprecation في تبعيات أدوات التطوير، وتحذير KGP من FlutterFire بشأن إصدارات Flutter المستقبلية؛ نسخة Flutter الحالية مثبتة وbuild ناجح.
