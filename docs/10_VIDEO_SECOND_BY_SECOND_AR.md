## جرد الأزرار والتفاعل (وظائف المرحلة الأولى)

| زر أو بطاقة | المكان | ما يجب أن يحدث فعلياً في نسخة الواجهة |
|---|---|---|
| الرئيسية | شريط التنقل | تعرض بطاقات مجمعة محسوبة من الطلبات المسموحة للمستخدم |
| بطاقات شركات التوصيل | الرئيسية | تعرض حالات وأعداد الطلبات والمبالغ حسب الصلاحية |
| بطاقة حالة داخل التوصيل | الرئيسية | تنقل لقائمة الطلبات مفلترة بمصدر التوصيل والحالة |
| بطاقة جميع الطلبات | الرئيسية | تعرض كل الطلبات بما فيها المرتبطة بالتوصيل؛ ليست متجر إلكتروني |
| بطاقة حالة ضمن جميع الطلبات | الرئيسية | تنتقل إلى القائمة مع فلتر الحالة لجميع الطلبات |
| المتأخرة | الرئيسية | تنتقل لطلبات لم تغلق بعد تجاوز 36 ساعة (عتبة تجريبية قابلة للضبط لاحقاً) |
| كل الطلبات | الرئيسية/القائمة | قائمة الطلبات المسموحة بالدور |
| إضافة طلب | تبويب الوسط وداخل القائمة | شاشة جديدة وبقاء الإسناد للشحن تحت الصلاحية |
| حفظ الطلب | نموذج الطلب | يتحقق من الحقول ثم يدخل بالذاكرة (لم يتم حفظ Firebase بعد) |
| بحث | قائمة الطلبات | بحث بالاسم والهاتف والرقم والمنشئ |
| نوع وحالة وشركة | قائمة الطلبات | فلاتر مشتركة للشركة والحالة والمصدر |
| بطاقة طلب | القائمة | صفحة تفاصيل: مستلم، وصف، مبلغ إن سمح، شركة، تتبع، سجل |
| تعديل | تفاصيل طلب | فقط إذا سمحت الحالة والدور |
| تغيير الحالة | تفاصيل طلب | يعرض النقلات اليدوية المسموحة فقط، لا يحاكي استجابة API |
| إسناد شركة توصيل | تفاصيل طلب | فقط للمصرح له ولشركة مفعلة وغير مؤرشفة؛ لا يرسل API حالياً |
| شركات التوصيل | الإعدادات | بطاقات شركة مفصلة وحالات الطلبات، للموظفين وفق نطاقهم |
| تعديل/أرشفة الشركة | شركات التوصيل | للمصرّح فقط، ولا تحذف علاقات الطلبات |
| اختبار الاتصال | شركة التوصيل | رسالة واضحة بأن الربط لم ينفذ؛ لا يدعي اختباراً حقيقياً |
| خريطة حالات الشركة | إعدادات API | حقول حالات خام وربط بحالات النظام، بيانات تجريبية |
| الموظفون والصلاحيات | الإعدادات | للمدير العام والمصرّح فقط |
| الإشعارات وقراءة الكل | شريط التنقل/الإشعارات | إشعارات موجّهة مع حالة قراءة مستقلة لكل مستخدم |
| تقارير وإحصائيات | الإعدادات | لمن لديه الصلاحية؛ تقارير تشغيلية لا محاسبة |
| سجل العمليات | الإعدادات | يسجل التعديلات التجريبية للطلب والحالة والشركة |
| تبديل المستخدم | الإعدادات | يعود لاختيار مستخدم تجريبي ويمنع الحساب الموقوف |

## عناصر ظاهرة بالفيديو لكنها مستبعدة صراحة

المتجر الإلكتروني، كتالوج المنتجات، صور المنتجات، إضافة منتج، نظام جرد المستودعات والمخزون، المصروفات، المالية المتقدمة، شبكة المسوقين، محادثة العملاء، نشر التطبيقات على متاجر Google وApple. إدراجها بسبب الفيديو يسبب توسع نطاق المشروع دون اتفاق.

## فروقات غير قابلة للتحقق من الفيديو وحده

لا يظهر في الفيديو أسلوب مصادقة شركة التوصيل ولا بنية REST/GraphQL ولا أمثلة Webhooks ولا دلالات الحالات التفصيلية لأي مزود. يجب طلب وثائق الشركة المتفق عليها قبل تنفيذ الموصل الحقيقي.
