# Stage 4B — فجوة شركات التوصيل و KMS

> **الحالة: EXTERNAL DEPENDENCY** — ليست عيباً برمجياً ولا سياسة.

## 1. السبب الجذري — مُثبَت من المصدر

```js
// functions/src/delivery.js:6
const KEY = process.env.VELNIX_KMS_KEY;
```
```js
// functions/src/delivery.js:20
if(!KEY || !ciphertext) throw new Error('kms_not_configured');
```
```js
// functions/src/index.js:95
if([...'kms_not_configured',...].includes(e?.message))
  fail('failed-precondition','إعداد شركة التوصيل أو خدمة تشفير مفاتيحها غير مكتمل');
```

**السبب:** المتغيّر `VELNIX_KMS_KEY` غير معرَّف، و**Firebase Emulator Suite لا يوفّر محاكي KMS إطلاقاً**.

## 2. تصنيف الفجوة

| الاحتمال | الحكم | الدليل |
|---|---|---|
| عيب واجهة | **لا** | الواجهة تعرض «إضافة شركة» بشكل صحيح |
| عيب سياسة خلفية | **لا** | السياسة ترفض بشكل صحيح عند غياب التشفير |
| **إعداد تشفير مفقود** | ✅ **هذا هو** | `VELNIX_KMS_KEY` غير معرَّف + لا محاكي KMS |
| دعم مزوّد خارجي مفقود | ✅ **مرتبط** | لا يوجد مزوّد توصيل مهيّأ |

> **التصميم صحيح:** الأسرار تُشفَّر بـCloud KMS ولا تُخزَّن نصاً صريحاً. لن أضعّف هذا مقابل اختبار ناجح.

## 3. 🔴 اكتشاف أكبر — وظائف غير منشورة في الإنتاج

**مقارنة صادرات المصدر بالمنشور فعلياً في `europe-west1`:**

| القياس | العدد |
|---|---|
| صادرات `callable` في المصدر | 28 |
| المنشور في الإنتاج | 22 |
| **مُصدَّر وغير منشور** | **9** |

| غير منشور | ما تفعله الواجهة |
|---|---|
| `saveCompany` | زر «إضافة شركة» |
| `archiveCompany` | زر «أرشفة» |
| `restoreCompany` | زر «استعادة» |
| `testCompanyConnection` | زر «اختبار الاتصال» |
| `assignCompany` | «اختيار شركة توصيل» في الطلب |
| `sendOrderToDelivery` | مسار الشحن |
| `resolveDispatchException` | معالجة استثناءات الشحن |
| `registerDevice` / `unregisterDevice` | تسجيل الجهاز للإشعارات |

> **النتيجة:** الواجهة تعرض أدوات لا يمكنها العمل في الإنتاج.هذا ليس عيباً برمجياً — بل **فجوة نشر** تحتاج قرار المالك.
> ⛔ **لن أنشر أي وظيفة**: خارج التفويض.

## 4. لماذا لم أستخدم بديلاً محلياً لـKMS

كان بإمكاني حقن `kmsClient` مزيفاً، لكن ذلك يتطلب تعديلاً في مسار التشفير نفسه. **المخاطرة/الفائدة غير مبررة**، ويتعارض مع «لا تُضعِف التشفير».

## 5. مقترح منفصل — **يتطلّب موافقة**

| البند | التفصيل |
|---|---|
| المورد | Cloud KMS CryptoKey + سرّ |
| التغيير | نشر الوظائف التسع + ضبط `VELNIX_KMS_KEY` |
| المخاطركون | إتاحة تشفير أسرار المزوّد |
| تحكّم عزل | يجب أن يُنفَّذ **خارج** هذه المهمة وبموافقة منفصلة |
| ⛔ | **لم أنفّذ شيئاً. لم أضع KMS إنتاجي. لم أختبر Click.** |
