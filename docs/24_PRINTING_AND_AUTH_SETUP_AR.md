# دليل الطباعة وتسجيل Google

## الطباعة

- من **تفاصيل الطلب** اختر «طباعة / PDF / باركود».
- كل طلب له `barcodeValue = VNX-<Firestore document id>`، لذلك لن يتغير الباركود عند إعادة الطباعة؛ ويتيح البحث في `searchOrders` استرجاع الطلب بالمسح.
- اختر A3 أو A4 أو A5 أو A6 أو Letter أو Legal أو طابعة 58/80 ملم أو مقاساً مخصصاً (عرض 50–420 ملم وارتفاع 80–600 ملم).
- اختر «طباعة» لفتح نافذة الطابعة أو «حفظ / مشاركة PDF». الـPDF يدعم العربية RTL عبر Cairo.
- **لا تبعث بيانات العميل للخارج عبر QR/رابط عام.** الباركود يحتوي رقم طلب فقط، والدخول للطلب يخضع لصلاحيات الموظف في Cloud Functions.
- نسخ الخط العربية قد تحتاج اتصالاً أولياً بالإنترنت؛ لا تعتبر الفاتورة قابلة للطباعة دون إنترنت من أول تشغيل بعد.
- يجب تجربة المخرجات عبر طابعة حرارية فعلية وماسح، لأن قياس رول الورق والقص يختلف حسب طراز الطابعة.

## Google Sign-In

1. فعّل Google داخل Firebase Authentication.
2. أضف SHA-1/SHA-256 اللازمة للأندرويد، URL scheme في iOS، Authorized domains للويب، واستخدم `flutterfire configure` للمنصات المطلوبة.
3. في Android/iOS/macOS يستخدم التطبيق `google_sign_in` v7.2، وفي Web يستخدم Firebase Popup؛ Windows/Linux يستخدمان بريد/كلمة مرور أو فتح نسخة الويب.
4. اربط UID الصحيح في `members/{uid}` بواسطة المدير/مسار bootstrap آمن، ولا تمنح صلاحيات لمجرد التحقق من عنوان البريد.
5. اختبر ربط البريد المسجل مسبقاً مع تسجيل Google؛ لا تسمح بإنشاء صلاحيات تلقائية لحساب OAuth جديد.

## التهيئة الخدمية

- إكمال `firebase.json` و`FIREBASE_*` و`FIREBASE_APPCHECK_SITE_KEY` عبر إعدادات النشر، دون نسخ أسرار المستخدم في المستودع.
- إعداد Cloud KMS key والسماح للخدمة بفك/تشفير الرموز، وضبط `ALLOWED_DELIVERY_HOSTS` المضيفين المصرح بهم فقط.
- اعتماد محول توصيل حقيقي حسب وثائق شركة محددة، واختبار Sandbox بما يشمل محاكاة timeout وWebhook.
