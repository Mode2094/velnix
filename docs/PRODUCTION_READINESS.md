# جاهزية الإنتاج
**غير معتمد للإنتاج.** العمل المحلي يزيل عيوباً مهمة ويضيف وسائل تحقق؛ لا يوجد نشر أو اتصال شركة أو تجربة جهاز/طابعة فعلية.

بوابات الاعتماد: مشروع staging صحيح؛ Auth وGoogle وApp Check على المنصات؛ KMS/IAM؛ فهارس واستعلامات بيانات واقعية وقياس زمن/تكلفة خاصة فرق >30 وعدادات؛ دورة carrier sandbox ثم اعتماد الإنتاج؛ FCM الأجهزة؛ توقيع Android وbuild iOS على macOS؛ طابعة وماسح؛ اختبار مستخدمين لكل الأدوار؛ CI بعيد ناجح؛ سياسات خصوصية واحتفاظ؛ تنبيهات ونسخ احتياطي وتجربة استعادة وrollback.

يُراجع كل بند مع دليل ومالك وتاريخ قبل إذن نشر مستقل. أي قيد زمني أو تغيير عقود API يستلزم تقييم جديد. لا يمكن استبدال بوابات الاعتماد باختبارات unit أو البحث النصي.

أغلقت عيوب الإكمال الداخلي واستعادة push والـpagination والطباعة المكتشفة. تبقى بوابات المرحلة السابقة كما هي؛ build Live ليس تسجيل دخول Live. قبول الباركود الفيزيائي ضروري خصوصاً 58 مم، لأن بعض صور 300 DPI لا تفك مباشرة وتحتاج preprocessing رقمي. يجب اعتماد تواتر retry للدفع ضمن الميزانية وسعة 25/دورة وحدود الأحداث المتزايدة؛ لا يوفر هذا ضمان exactly-once أو زمن استجابة لحظي عند الفشل.
