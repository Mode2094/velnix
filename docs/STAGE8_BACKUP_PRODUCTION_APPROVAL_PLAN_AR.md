## 2. الحزمة الموصى بها (عرض للقرار — غير مُنفَّذ)

| المكوّن | القيمة المقترحة | السبب |
|---|---|---|
| PITR | مُفعَّل | أرخص تعافٍ من الأخطاء الحديثة (حذف/كتابة) بدقة دقيقة |
| جدول يومي | `--recurrence=daily` باحتفاظ مقترح 7–14 يوماً | غطاء يومي مستقل عن PITR |
| جدول أسبوعي | `--recurrence=weekly --day-of-week=MON` باحتفاظ مقترح 8 أسابيع | أفق أطول ضمن سقف 14 أسبوعاً |
| تصدير Bucket | شهري يدوي بموافقة + سياسة حياة | أرشفة قابلة للتنزيل للمالك خارج النسخ المُدارة |
| Auth export | شهري إلى خزنة المالك | لا يغطيه أي مما سبق |
| مراقبة | تنبيه على غياب نسخة اليوم + فشل الجدولة | النسخ الصامت الفاشل أخطر من غيابه |

**سقف مهم:** لكل قاعدة جدول يومي واحد + أسبوعي واحد فقط، ووقت التنفيذ داخل اليوم لا يُحدد (UTC). النسخ في موقع القاعدة `nam5`.

## 3. أوامر التنفيذ (جاهزة — تُنفَّذ فقط بعد الموافقة وبترتيب البوابات)

> جميع الأوامر أدناه مُتحقَّق من صيغتها من `gcloud ... --help` المحلي ووثائق Google. **لم تُنفَّذ ولا واحد منها.**

**بوابة G1 — PITR (موافقة D2):**
```bash
gcloud firestore databases update --database='(default)' \
  --enable-pitr --project=velnix-6c1a2
# التحقق:
gcloud firestore databases describe --database='(default)' \
  --project=velnix-6c1a2 | grep pointInTimeRecoveryEnablement
```
- ملاحظة: النافذة تتراكم تدريجياً حتى 7 أيام؛ `versionRetentionPeriod` تصبح 7 أيام خلال أسبوع.
- الصلاحية اللازمة: صلاحيات `datastore.databases.update` (أو `roles/datastore.owner` — يُفضَّل دور مخصص أقل امتيازاً).

**بوابة G2 — جداول النسخ (موافقة D3):**
```bash
gcloud firestore backups schedules create --database='(default)' \
  --recurrence=daily --retention=7d --project=velnix-6c1a2
gcloud firestore backups schedules create --database='(default)' \
  --recurrence=weekly --day-of-week=MON --retention=8w --project=velnix-6c1a2
# التحقق:
gcloud firestore backups schedules list --database='(default)' --project=velnix-6c1a2
gcloud firestore backups list --location=nam5 --project=velnix-6c1a2
```
- الصلاحية اللازمة: `roles/datastore.backupSchedulesAdmin`.
- تكلفة: تخزين النسخ وفق التسعيرة الرسمية (GB-شهر × الحجم الفعلي؛ النسخ قابلة للضغط من جهة المزود — تُقاس من فاتورة فعلية).

**بوابة G3 — Bucket للتصدير (موافقة D4):**
```bash
gcloud storage buckets create gs://VELNIX-BACKUP-BUCKET-NAME \
  --project=velnix-6c1a2 --location=nam5 --uniform-bucket-level-access
# Export كامل يدوي (يدعم نقطة PITR الزمنية بعد تفعيل G1):
gcloud firestore export gs://VELNIX-BACKUP-BUCKET-NAME/exports/$(date -u +%Y%m%dT%H%M%SZ) \
  --project=velnix-6c1a2 [--snapshot-time='YYYY-MM-DDTHH:MM:SSZ']
```
- الصلاحية: `roles/datastore.importExportAdmin` + `roles/storage.objectAdmin` على الـBucket فقط.
- تكلفة: قراءات تصدير × تسعيرة Firestore + تخزين GCS (تُدار بسياسة حياة من المالك).

**بوابة G4 — استعادة (لكل حادثة بموافقة منفصلة):**
```bash
# النمط الآمن أولاً: استعادة إلى قاعدة جديدة للمعاينة (لا للمس (default))
gcloud firestore databases restore \
  --source-backup=projects/velnix-6c1a2/locations/nam5/backups/BACKUP_ID \
  --destination-database=velnix-recovery-preview --project=velnix-6c1a2
```
- الصلاحية: `roles/datastore.restoreAdmin`.
- الاستعادة إلى `(default)` مباشرة **ممنوعة في هذا الـRunbook** إلا في كارثة C من تصنيف القسم 1 وبموافقة مكتوبة في سجل الحادث.
- الوجهة تُنشأ في نفس موقع النسخة (`nam5`) بلا استثناء.

## 4. IAM بأقل امتياز وفصل أدوار

| الدور | من يحمله | الغرض |
|---|---|---|
| `roles/datastore.backupSchedulesAdmin` | مهندس المنصة (بناء) | إنشاء/تعديل الجدولة |
| `roles/datastore.backupsAdmin` | مهندس المنصة | إدارة النسخ نفسها |
| `roles/datastore.backupsViewer` | المراجع/المدقق | قراءة حالة النسخ |
| `roles/datastore.restoreAdmin` | مسؤول الاسترجاع فقط | تنفيذ الاستعادة |
| `roles/datastore.importExportAdmin` | هوية التصدير | export/import إلى الـBucket |
| `roles/datastore.viewer` | المراقبة | القراءة العامة |
| `roles/storage.objectAdmin` (مقيد بالBucket) | هوية التصدير | الكتابة في Bucket النسخ فقط |

**فصل واجب:** المنفّذ لا يملك صلاحية نشر الدوال/القواعد، والمراجع (Verify reviewer) مستقل عن منفّذ الاستعادة.
