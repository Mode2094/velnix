# الاعتمادات الخارجية الباقية بعد المرحلة الرابعة

> تحديث طلب المالك الحالي: التجربة والتسليم النهائي على مشروع واحد velnix-6c1a2. [وثيقة ربط المشروع الحالي](FIREBASE_CURRENT_PROJECT_SETUP_AR.md) تحدد التسجيلات والإعدادات المحلية والقيود. افتراض مشروع Staging مستقل في الخطط السابقة أُلغي بهذا الطلب؛ قيمة staging الآن لا تثبت عزل البيانات، ولا تسمح بتشغيل اختبارات المسح أو الاستعادة على المشروع الحقيقي. لا إنشاء موارد أو فوترة أو Deploy في هذا الطلب.

| المطلوب من المالك | ما يفتحه وما لم يثبت بعد |
|---|---|
| تأكيد تسجيلات مشروع velnix-6c1a2 الحالية، App Check/Nطاقات وسلامة الخدمات القائمة | SDK configs جهزت محلياً؛ نشر لاحق إن احتاجه Backend ممنوع حالياً، ولا مشروع/فواتير/موارد أنشئت |
| Auth/OAuth/SHA وAuthorized Domains وApp Check | دخول ورفض وصول حقيقي؛ المحاكي لا يثبت App Check المنشور |
| runtime service account محدود وKMS key reference وسياسة IAM | تشفير/فك وأقل صلاحيات فعلية؛ الأمثلة ليست grants |
| FCM/VAPID/Worker وAPNs/قدرات iOS وموافقة الإذن | إشعارات foreground/background، خروج offline وسحب device token على أجهزة |
| Mac/Xcode وApple signing وAndroid signing محفوظة بأمان | iOS compile وتجربة الأجهزة؛ Android الحالي Debug وليس إصداراً موقعاً للتسليم |
| استجابات Click الرسمية منزوعة الأسرار، method/endpoint/auth/status/IDs/money/idempotency | إكمال Adapter واختباره بمهمة مفوضة؛ generic_v1 غير متوافق افتراضياً |
| حساب Click sandbox وhost محدد بعد اكتمال العقد | اختبار حقيقي لاحق فقط؛ لا اتصال بالشركة أو shipment حالياً |
| أجهزة مستهدفة وطراز طابعة/ماسح ودقة وأحجام معتمدة | قبول UX/طباعة فعلية؛ PDF وgoldens ليسا تجربة جهاز |
| أهداف p95 والكلفة والاحتفاظ وRPO/RTO ومسؤول التشغيل | ضغط/نسخ/استعادة/تراجع مقاسة دون أهداف مفترضة |
| مراجعة صاحب المشروع وقبول مكتوب في المرحلة الخامسة | اعتماد الوظائف والهوية والنصوص؛ لا حاجة للمراجعة الآن |

لا ترسل كلمات مرور أو tokens أو service-account/signing files في المحادثة. الأمثلة العامة في config فارغة؛ مدخلات التشغيل محلية مستثناة وخزنة المالك. [خطة التهيئة](SAFE_CONFIGURATION_HANDOFF_AR.md)، [قبول المرحلة الخامسة](STAGING_ACCEPTANCE_PLAN.md)، [الاستعادة](BACKUP_RESTORE_ROLLBACK_AR.md)، [أسئلة Click](CLICK_DELIVERY_QUESTIONS_AR.md).

فهارس109 تحتاج READY في المشروع الحقيقي. حدود push الحالية25 حالة مستحقة/دورة15 دقيقة/45 ثانية و4 محاولات/lease2 دقيقة؛ تقاس مقابل الحمل لاحقاً. poll100 شحنة لا يثبت Click. حالات الإرسال الملتبسة لا يعاد إنشاؤها تلقائياً؛ الحسابات المالية غير الموثقة تبقى مجهولة.

GitHub API: CONNECT403 من proxy البيئة ليس إثبات نقص صلاحيات GitHub أو عيب Velnix. صفحات GitHub HTML وGit HTTPS تعمل لقراءة حالة CI وحفظ المصدر؛ API ليس شرطاً لقراءة الحالة بهذه الوسيلة. عند الحاجة للـAPI، فعّل api.github.com في إعدادات شبكة البيئة ثم أعد الفحص؛ إذا ظهر401/403 من GitHub نفسه بعدها راجع binding/SSO/App permissions. لا تطلب PAT في المحادثة. نتيجة CI يجب نسبتها إلى SHA النهائي، لا إلى024c1a7 أو e005c66 تلقائياً.

العمل محصور بفرع التطوير، لا Merge/Deploy أو إنتاج أو متجر/مخزون/محاسبة جديدة. المرحلة الخامسة كاملة غير معتمدة حتى إغلاق بوابات Firebase وClick والأجهزة والاستعادة ومراجعة المالك.
