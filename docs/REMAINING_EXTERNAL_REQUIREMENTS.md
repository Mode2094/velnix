# المتطلبات الخارجية الباقية
| المطلوب من المالك | الغرض |
|---|---|
| project ID والمنطقة وإعداد العميل العام لمشروع staging | تهيئة واختبار المسار الحقيقي |
| اعتماد معرفات التطبيقات وOAuth وSHA وApp Check | دخول وتوثيق على الأجهزة |
| هوية خدمة ومرجع KMS/IAM عبر أدوات آمنة | تشفير مفاتيح الشركات |
| وثائق شركة واحدة وعقدها وحساب sandbox في مدير الأسرار | تكامل حقيقي موثق |
| إعداد FCM/VAPID واعتماد تجربة الإذن | دفع إشعارات فعلي |
| Android signing وMac/Xcode وحساب Apple | builds قابلة للتوزيع |
| طراز الطابعة والماسح وأجهزة اختبار | تحقق الإيصالات والباركود |
| اعتماد الهوية والأيقونات والنص القانوني | اكتمال المنتج |
| أهداف الأداء والميزانية وRPO/RTO وسياسة الاحتفاظ | اختبار staging وخطة تشغيل/استعادة |
| موافقة نشر محددة بعد نتائج staging | نقل للإنتاج |

لا ترسل كلمات المرور أو ملفات service-account أو مفاتيح التوقيع في المحادثة. إعداد بيئة التطوير السحابية منفصل عن نشر التطبيق. Local-only commits محفوظة في هذا workspace؛ استعادتها في مهمة جديدة غير مثبتة ما لم تحفظ snapshot أو تنشر العمل بتفويض.
