## 2. هيكل البيانات الذي يجب أن تغطيه النسخة

| المسار | المحتوى | الحساسية | العلاقات/ملاحظات |
|---|---|---|---|
| `members/{uid}` | الاسم، الدور، الصلاحيات، `active`، `salesSupervisorId`، `approvalStatus` | عالٍ (هوية/صلاحيات) | `uid` يجب أن يطابق مستخدم Firebase Auth |
| `joinRequests/{uid}` | طلبات الانضمام ونتائجها | متوسط | مرتبط بـAuth |
| `orders/{id}` | بيانات الطلب والمال (fils)، `status`, `dispatchState`, `revision`, `companyId`, أقفال الإرسال | عالٍ (بيانات عملاء) | `createdBy → members`، `companyId → companies` |
| `orders/{id}/events/{eventId}` | سجل دورة حياة الطلب | عالٍ (تدقيق) | يُقرأ في شاشة الطلب |
| `companies/{id}` | إعدادات شركة التوصيل و`statusMap` | متوسط | `companySecrets/{id}` |
| `companySecrets/{id}` | **نص مشفَّر بـKMS** | عالٍ | **بلا قيمة دون نفس مفتاح KMS وإصداره وصلاحية الفك** |
| `deliveryInbox/{companyId}/events/{eventId}` | أحداث المزامنة من الشركات | متوسط | الأب `deliveryInbox/{companyId}` **مستند ضمني** لا تعيده استعلامات المجموعات |
| `notices/{id}` | الإشعارات الداخلية + `pushState` | متوسط | `recipientId → members` |
| `devices/{id}` | رموز FCM | عالٍ (اعتمادات دفع) | الرموز المستعادة **غير موثوقة** |
| `auditEvents/{id}` | سجل التدقيق | عالٍ (تدقيق) | استعادة أقدم = تراجع سجل التدقيق — قرار مالك |
| `idempotency/{key}` | مفاتيح منع تكرار إنشاء الطلبات | متوسط | تُستعادة متسقة مع الطلبات |
| `settings/system` | إعدادات النظام | منخفض | مطلوب لإعادة التشغيل |
| `settings/bootstrapState` | قفل التمهيد الأول | عالٍ تشغيلياً | عدم تطابق العضو/القفل قد يقفل التمهيد خطأً |

**مستندات الأب الضمنية:** Firestore لا يخزّن مستند الأب عند وجود مجموعة فرعية فقط (حالة `deliveryInbox/{companyId}`). لذلك تكتشف أداة المحاكي الفرعيات عبر Collection Group بالأسماء المعروفة (`events` — `KNOWN_SUBCOLLECTION_IDS`)؛ أي اسم مجموعة فرعية جديد مستقبلاً يجب إضافته للأداة (بند فحص دائم في Runbook).

## 3. نطاق ما تغطيه نسخة Firestore — وما لا تغطيه

| الأصل | داخل النسخة؟ | ملاحظة |
|---|---|---|
| Collections + Subcollections | ✅ | يشمل الفرعيات تحت الآباء الضمنية |
| **Firebase Auth (مستخدمون، providers، password hashes)** | ❌ **لا** | مسار مستقل: `firebase auth:export` إلى خزنة المالك (شديد الحساسية — لا Git ولا جهاز غير معتمد) |
| Cloud KMS (مفاتيح/إصدارات) | ❌ | حماية مستقلة بمنع التدمير — الفقدان غير قابل للتعويض |
| GCS (بيانات تطبيقية) | ❌ (غير مستخدم حالياً) | سياسة منفصلة لو أُضيف لاحقاً |
| Rules · Indexes · IAM · Env Vars (`VELNIX_KMS_KEY`, `ALLOWED_DELIVERY_HOSTS`) · App Check · FCM/APNs | جزئياً | القواعد والفهارس في Git؛ الباقي في Release Manifest خارج النسخة |
| حالة Click الخارجية | ❌ | لا يتراجع أي إجراء خارجي باستعادة قاعدة بيانات |
| رموز FCM | ⚠️ تُنسخ لكنها غير موثوقة | إعادة التسجيل بعد الاستعادة إجراء بشري |

## 4. مقارنة الخيارات الرسمية

> **منهجية التكلفة (بلا أرقام مُخترعة):** الحساب دائماً = (حجم فعلي × تسعيرة الوحدة من [صفحة تسعير Firestore](https://cloud.google.com/firestore/pricing) وقت القرار) + قراءات/كتابات التصدير والاستيراد + تخزين GCS. القاعدة الحالية صغيرة (~17 مستنداً) و`freeTier: true`، لذا التكلفة الفعلية اليوم ضئيلة — لكن التسعيرة الرسمية تُقرأ وقت قرار التفعيل ولا تُقدَّر من الذاكرة.

| | **PITR** | **Managed Backups (جداول)** | **Export/Import → GCS** | **أداة المحاكي (المبنية هنا)** |
|---|---|---|---|---|
| الغرض | التراجع عن حذف/كتابة خاطئة حديثة | نسخ دورية يديرها النظام | أرشفة/نقل يدوي أو مجدول | تمرين ومنعطفات واختبار منطق فقط |
| التغطية | نسخة/دقيقة داخل نافذة 7 أيام | نسخ كاملة (يومي وأسبوعي) | كامل القاعدة إلى Bucket | قاعدة المحاكي فقط |
| RPO | دقائق (دقة دقيقة واحدة) | ≤24 ساعة (يومي) / أسبوع (أسبوعي) | وقت آخر تصدير | غير إنتاجي |
| RTO | غير مختبر: clone/export من نقطة زمنية + تحقق | غير مختبر: استعادة من نسخة + تحقق | غير مختبر: استيراد + تحقق | ثوانٍ–دقائق (محاكي) |
| التفعيل حالياً | **معطّل** — يتطلب تفعيلاً وبالفوترة | **لا جداول** — يتطلب بالفوترة | يتطلب Bucket + أمر مصادق | جاهز الآن (بلا سحابة) |
| الاحتفاظ | 7 أيام (يتراكم تدريجياً بعد التفعيل) | حتى 14 أسبوعاً؛ يومي واحد + أسبوعي واحد للقاعدة؛ وقت التنفيذ غير قابل للتحديد داخل اليوم (UTC) | سياسة حياة GCS يحددها المالك | ملف محلي يحذفه المشغّل |
| IAM (وثائق Google) | يمنحه `roles/datastore.owner` أو صلاحيات `datastore.databases.*` | `roles/datastore.backupSchedulesAdmin` + `roles/datastore.backupsAdmin` / `backupsViewer` | `roles/datastore.importExportAdmin` + كتابة Bucket | لا اتصال سحابي (loopback فقط) |
| التشفير | Google-managed at-rest | Google-managed at-rest | + تشفير GCS والمفتاح المُدار | بيانات اصطناعية فقط |
| أثر البيانات الأحدث | تُفقد كتابات ما بعد النقطة (قابلة للتصدير للمراجعة قبل الاستعادة) | تُفقد كتابات ما بعد النسخة | الاستيراد **لا يحذف** ما ليس في الملف | لا ينطبق |
| Triggers/إشعارات مكررة | قد تعود `pushState` للخلف | كذلك | كذلك | لا دوال تعمل أثناء التمرين |
| Auth/KMS/Click | لا يغطيها | لا يغطيها | لا يغطيها | لا ينطبق |
| الحكم | مُرشَّح للتفعيل **بموافقة** | مُرشَّح للتفعيل **بموافقة** | أداة مساندة وتمرين | **مُنفَّذ ومُختبَر** |

**حدود صريحة:**
- **PITR:** لا تبدأ القراءة من 7 أيام فور التفعيل (تراكم تدريجي، والحد الأدنى ساعة قبل التفعيل)؛ لا free tier؛ التعطيل يمحو النافذة بمرور الوقت؛ الاسترجاع عبر clone/تصدير — لا استرجاع جزئي مستندي مباشر.
- **Managed Backups:** النسخة في موقع القاعدة (`nam5`)؛ لا تحكم بوقت التنفيذ؛ لا تغطي Auth/KMS/IAM/GCS.
- **Export/Import:** الاستيراد دمج — لا يحذف الأحدث — فالـ«رجوع الزمني» فوق قاعدة حية يحتاج قاعدة جديدة أو معالجة بشرية موثقة.
- **أداة المحاكي:** نجاحها **لا يثبت** Managed Restore أو PITR؛ ترفض أي هدف غير `demo-*` أو غير loopback بلا خيار تجاوز.

**RPO/RTO — خيارات جاهزة لقرار المالك (لا SLA مفترض):**

| الحزمة | RPO متوقع | RTO متوقع (غير مختبر سحابياً) | ملاحظة |
|---|---|---|---|
| تصدير يدوي قبل كل مرحلة | ساعات–أيام | ساعات | حد أدنى مؤقت، غير كافٍ للتشغيل اليومي |
| PITR + نسخ يومي | دقائق | ساعات + زمن تحقق بشري | الأقوى للحوادث الحديثة |
| نسخ يومي فقط | ≤24 ساعة | ساعات | أبسط وأرخص نسبياً |
| نسخ أسبوعي فقط | ≤7 أيام | ساعات | غير مناسب لبيانات الطلبات اليومية |

**الهدف النهائي (RPO/RTO) قرار مالك صريح — لا يُثبَّت في هذه الجولة.**

### الحكم

- **LOCAL PASS** — الأداة والسيناريوهات الـ12 والاختبارات الآلية (وحدة + محاكي) ناجحة بالكامل.
- **PRODUCTION NOT VERIFIED** — لا نسخة سحابية مطلوبة ولا مُفعَّلة، ولم يُختبر أي استرجاع سحابي. لا يُنشر أي وعد RTO إنتاجي قبل تمرين حقيقي مصرح به.
- **BLOCKED (اختياري المالك)** — تفعيل PITR/الجداول/تصدير GCS محجوب على موافقة مالك صريحة وميزانية وتحديد RPO/RTO، وفق خطة الموافقات.
