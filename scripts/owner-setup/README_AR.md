# توثيق أول مدير عبر Google — تشغيل مؤقت بلا نشر

1. افتح Google Cloud Shell على المشروع velnix-6c1a2 بحساب مشغل مخول. ارفع ZIP إلى مجلدك الخاص.
2. شغّل الأمر الواحد المبين في التقرير: فك الملف ثم bash velnix-owner-setup/start.sh وبريد المرشح.
3. اسمح بالمصادقة الرسمية للمشغل إن طلبها gcloud؛ هذه مختلفة عن جلسة Firebase للمرشح. لا تنقل ADC أو tokens خارج Cloud Shell ولا توافق على أي فوترة أو تفعيل API أو IAM جديد.
4. المسار يفحص Auth وmembers وjoinRequests وbootstrapState أولاً. لا يفسر تعذر الوصول كخلو، ويقف إن وجد عضويات أو قفلاً أو طلبات قديمة، أو حساباً آخر. يسمح باستئناف حساب Google المرشح الموجود وحده دون حذفه.
5. يفحص Google provider وتسجيل Web المحدد وحالته ACTIVE وإعداد SDK الفعلي. إذا كان المزود غير جاهز، يعطي رابط Console الدقيق بدلاً من اختلاق OAuth client أو طلب client secret. لا يعطل Email/Password أو App Check ولا يغير إعدادات المشروع تلقائياً.
6. عند ظهور رسالة جاهزية الطرفية افتح Web Preview على8080 في تبويب مستقل. هذه صفحة في Cloud Shell وليست Firebase Hosting أو Deploy. إذا لم يكن نطاق المعاينة مصرحاً، تعرض الصفحة النطاق المحدد لإضافته إلى Authentication → Settings → Authorized domains، ثم حدّثها. لا تضف wildcard. هذا إعداد Google Auth مطلوب، وليس نشراً؛ يبقى بيد المشغل المخول.
7. بعد اكتمال هذه الإعدادات اضغط «المتابعة باستخدام Google» واختر الحساب المرشح مرة واحدة. إن فرض مشروع Auth App Check ولم تجهز إعداداته الفعلية يفشل الدخول؛ لا تعطّل enforcement لتجاوزه. لا نجاح سحابي مفترض من فحوص المصدر.
8. token يرسل داخل جسم POST إلى خادم المعاينة الخاص نفسه فقط، ولا يكتب في URL أو logs أو ملف. الخادم يتحقق من توقيع Firebase والمشروع والإلغاء وgoogle.com والبريد الموثق ووقت الدخول وUID وسجل Google الفعلي، ثم يعيد فحص الجرد.
9. يشغّل bootstrap_admin.js بلا --apply بالـUID المتحقق منه. ينتج تقرير UID وgoogleSessionVerified وbootstrapDryRun فقط؛ لا عضوية فعالة ولا نشر. أرسل JSON النتيجة المنقح، ولا ترسل token أو ملف اعتماد. أي منح generalManager يحتاج الموافقة المحددة اللاحقة؛ الدور يمنح جميع صلاحيات Velnix ضمن السياسة القائمة.

الاعتمادات تبقى لدى المالك في ملف ADC الرسمي خارج Git؛ access tokens وID token في الذاكرة فقط، وجلسة المتصفح inMemory وتخرج بعد الفحص. يغلق الخادم بعد30دقيقة، ويمكن إيقافه بـCtrl+C. لا تنشئ حزمة من مجلد Cloud Shell بعد المصادقة؛ الحزمة الأصلية لا تتضمن credentials أو إعدادات SDK المحلية أو node_modules. أخطاء API لا تطبع الأجسام الحساسة.

لا يمكن إعطاء رابط Firebase دخول صالح من بيئة Codex قبل تشغيل هذا المسار بحساب مخول ومعرفة المزود والنطاق. فتح Cloud Shell بحد ذاته ليس تسجيل Firebase ولا يثبت UID. فحص CI والنشر والأجهزة والأدوار الخمسة الفعلية يبقى منفصلاً، ولا ينفذ هذا المسار Click أو طباعة أو شحنات.
